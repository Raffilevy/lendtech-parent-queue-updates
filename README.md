# LendTech Parent Queue Updates

This repository hosts update metadata for the LendTech Parent Queue desktop app.

## Updating the app

1. Upload the latest installer somewhere downloadable, ideally a GitHub Release asset.
2. Update `latest.json` with the new version and download URL.
3. The app will compare `latest.json.version` with its installed version.

## Bug reports

The app can create a prefilled GitHub issue with safe diagnostics. Do not paste passwords, cookies, tokens, or private browser session files into reports.
